📌 Rumus Baku

Rumus Dasar:
Ss = 2(S−1)  |  Int = P / S  |  R₁ = P − (Ss − S)

Pola Perputaran:
R₁ = R₁
R₂ = R₁ + 1×Int  |  R₃ = R₂ + 2×Int  |  R₄ = R₃ + 3×Int  |  R₅ = R₄ + 4×Int
R₆ = R₁ − 1×Int  |  R₇ = R₆ + 1×Int  |  R₈ = R₇ + 2×Int  |  R₉ = R₈ + 3×Int  |  R₁₀ = R₉ + 4×Int
R₁₁ = R₁ − 2×Int  |  ... dan seterusnya
